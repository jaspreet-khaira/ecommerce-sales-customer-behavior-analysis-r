# E-Commerce Sales & Customer Behavior Analysis using R

## 📌 About the Project

This project analyzes **E-Commerce sales data and customer behavior using R**. The main purpose is to explore sales performance, customer purchasing patterns, product performance, and revenue trends through data analysis and visualization.

The project demonstrates the use of R for **data cleaning, exploratory data analysis (EDA), data visualization, and extracting meaningful business insights**.

## 🎯 Objectives

- Analyze overall sales performance
- Understand customer purchasing behavior
- Identify top-performing products and categories
- Analyze sales and revenue trends
- Identify high-value customers
- Calculate important sales metrics
- Create meaningful data visualizations
- Generate useful business insights

## 🛠️ Tools & Technologies

- R
- RStudio
- tidyverse
- dplyr
- ggplot2
- tidyr
- lubridate

## 📊 Analysis

The project covers:

- Data cleaning and preprocessing

## 🚀 How to Run

1. Install **R** and **RStudio**.
2. Clone or download this repository.
3. Open the `.R` file in RStudio.
4. Install the required packages:

```r
install.packages("tidyverse")
install.packages("lubridate")
```

5. Run the R script to perform the analysis.
